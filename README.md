RedditModAssistant
​[UA] RedditModAssistant — це бот для автоматизації модерації Reddit, який використовує аналіз "червоних прапорців" для виявлення підозрілих акаунтів та спаму.
[EN] RedditModAssistant is a Reddit moderation bot that uses red-flag detection logic to identify suspicious accounts and filter spam.
​🇺🇦 Українською
​🚀 Функціонал
​OSINT-аналіз користувача: Перевірка віку акаунта та рівня карми.
​Фільтрація контенту: Пошук стоп-слів (спам, шахрайство).
​Автоматичне реагування: Попередження користувачів та сповіщення модераторів.
​🛠 Налаштування (Secrets)
​Для роботи потрібні: REDDIT_CLIENT_ID, REDDIT_CLIENT_SECRET, REDDIT_USERNAME, REDDIT_PASSWORD.
​🇺🇸 English
​🚀 Features
​User Reliability Check: Analyzes account age and total karma.
​Content Filtering: Scans comments for banned keywords.
​Smart Response: Automatically replies to suspicious comments.
​⚙️ Logic Settings
​MIN_ACCOUNT_AGE_DAYS: 7
​MIN_KARMA: 10
